Project Prompt Teacup is a project to develop a game from scratch and release it on Steam. The purpose of teacup is carry the project all the way to completion, and to learn if solo game development is a viable career pivot for me. In accordance with that goal, I have laid out three goals.

- Release the game on time. The target release date is provisional, and may be changed if there is a good reason. The target release date is mid-January.
- Make a non-trivial amount of money. Trying to pin down the exact amount that would be acceptable is like trying to form an egg yolk into a neat  triangle. The net revenue target is $2,000 per month spent in development. If it releases half way through January, that would be $9,000.
- Get "Overwhelmingly Positive" reviews on Steam. This is the only target that is more or less written in stone.

If these goals are met, the project will be considered a complete success.
